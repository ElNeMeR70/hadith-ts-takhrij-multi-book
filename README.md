- **المجال (Domain):** علوم الحديث الشريف وتحليل الأسانيد (Hadith Sciences & Isnad Graph Analytics)
- **الأداة (Module):** مخرّج الأحاديث الآلي في الكتب التسعة ومصادر السنة — *Automated Hadith Takhrij Cross-Indexer Across Kutub Al-Sittah*
